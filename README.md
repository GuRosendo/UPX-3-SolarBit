# UPX-3-SolarBit

## Trabalho UPX-3 - SolarBit

O SolarBit é um projeto acadêmico voltado à energia solar, com o objetivo de explorar soluções sustentáveis e promover o uso de fontes de energia renováveis.

O projeto busca contribuir para a conscientização sobre a importância da energia solar e suas aplicações, incentivando práticas mais eficientes e sustentáveis.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como acessar o projeto

Clone o repositório utilizando o comando:

git clone https://github.com/GuRosendo/UPX-3-SolarBit.git

Acesse a pasta do projeto:

cd UPX-3-SolarBit
